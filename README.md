# The Prime Art — static site

- `index.html`: home page. `assets/site.css` and `assets/site.js` are shared by every page.
- `journal/`: editorial guides linked from Features.
- `prize-rules.html`, `terms.html`, `privacy.html`: draft policies.
- `config.js`: form links, payment links, contact email and legal business details. Empty values stay hidden; once filled, buttons and the footer line appear.
- Tally: name the hidden fields `name`, `email`, `link`, `medium` (opening notice) and `name`, `email`, `package`, `note` (enquiry) so answers typed on the site arrive pre-filled.
- Placeholders that need real information are marked with the dashed `TBA` / "To be announced" label.
- Deploy: GitHub Pages from `main`, root.
