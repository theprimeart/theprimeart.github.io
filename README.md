# The Prime Art — static site

- `index.html`: the whole site (single page). Edit text directly or ask Claude in the project thread.
- `config.js`: form and payment links. Empty values hide nothing yet; once filled, buttons point to them.
- Deploy: push this folder to a GitHub repository and turn on GitHub Pages (Settings → Pages → Deploy from branch, root).
- Custom domain: add a `CNAME` file containing the domain, and point the domain's DNS to GitHub Pages.
